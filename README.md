# NEXUS: GOD-MODE 🔥

An interactive audio-reactive particle system built with vanilla JavaScript and Canvas API.

## 🎮 [LIVE DEMO](https://ranag786tech-lang.github.io

## ✨ Features
- Real-time microphone audio reactivity
- Elastic collision physics between nodes
- Generative music synthesis (collisions create tones)
- 8-way kaleidoscope mode
- Multiple color palettes
- Screen shake & camera effects
- Touch & gyroscope support

## 🛠️ Technologies
- HTML5 Canvas API
- Web Audio API
- Vanilla JavaScript (no frameworks)
- CSS3 animations

## 🎯 Controls
- **Q** - Supernova explosion
- **W** - Toggle wave/neural mode
- **K** - Toggle kaleidoscope
- **Mouse** - Attract nodes
- **Click** - Spawn particles

## 💡 Technical Highlights
- Dual-canvas rendering for glow effects
- Real elastic collision physics with rotation matrices
- Audio frequency analysis (FFT)
- Performance optimized (60 FPS with 100+ nodes)
- Mobile-responsive with touch support
